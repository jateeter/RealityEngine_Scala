## Why this is a pointer

The specification used to exist as a canonical copy in `RealityEngine_CPP`
plus byte-identical duplicates in `RealityEngine_LSP`, `RealityEngine_Scala`
and `RealityEngine_Manager`, with a CI check asserting the four never drifted.

Four copies of one contract is a contract that drifts. On 2026-08-27 two
changes landed in parallel — one in `RealityEngine_CPP`, one in
`RealityEngine_Scala` — that documented the *same* `POST /api/reset`
post-state in different words. Both were correct. The drift check failed and
`main` went red, because agreement on meaning is not byte equality.

A single master cannot drift from itself. The check that used to diff four
copies now asserts that each runtime repository holds this pointer and not a
fork of the specification.

## What the specification covers

The HTTP surface every runtime implements — Reality Engine and Perception
Engine endpoints, request and response shapes, and the semantics each runtime
must agree on. It binds all four runtimes: the C++, LSP and Scala engines, and
the TypeScript Perception Engine in `RealityEngine_Manager`.

Related contracts, also single-source, live in `RealityEngine_Machines/docs/`:
`PE_METRICS_CONTRACT.md`, `ARBITER_CONTRACT.md`, `SEMANTIC_AUDIT_CONTRACT.md`,
`SEMANTIC_GUARDRAIL_CONTRACT.md`.
